Mac选择macos-arm64（AppleSilicon）或macos-x64（Intel）的DMG。Windows优先安装windows-x64-setup.exe；ZIP用于便携解压运行。Windows需要微软WebView2运行时，通常系统已有。

旧1.0.0需要手动安装本版一次，之后才能收到应用内自动更新提示。关闭应用后替换安装即可；不要删除应用数据目录。

当前Mac为临时签名、尚未Apple公证，Windows暂无发行者签名证书。安装可能出现系统发行者提示。定时学习需要应用运行和电脑唤醒。
